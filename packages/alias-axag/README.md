# axag

AXAG CLI — generate Semantic Manifests and MCP tools from axag-* annotations. Wrapper for @web-axag/cli.

```bash
npx axag --help
```

This package exists so `npx axag` works without an install. It contains no logic of its own: it depends on [`@web-axag/cli`](https://www.npmjs.com/package/@web-axag/cli) and runs its binary. Install `@web-axag/cli` directly if you want the library as well.

Documentation: https://axag.org
