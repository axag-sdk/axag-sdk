# axag-lint

Lint AXAG annotations in HTML, JSX, TSX and Vue. Wrapper for @web-axag/lint.

```bash
npx axag-lint --help
```

This package exists so `npx axag-lint` works without an install. It contains no logic of its own: it depends on [`@web-axag/lint`](https://www.npmjs.com/package/@web-axag/lint) and runs its binary. Install `@web-axag/lint` directly if you want the library as well.

Documentation: https://axag.org
